# Тесты для проекта laba_8_on_condition

## Обзор

Этот проект содержит комплексные unit-тесты для приложения отслеживания курсов валют. Тесты покрывают все основные компоненты системы, включая модели данных, утилиты API и HTTP-обработчики.

## Структура тестов

### 1. `test_model.py` - Тесты моделей данных

Тесты для всех основных классов модели:

- **Author** - Проверяет создание автора, валидацию данных, геттеры/сеттеры
- **App** - Проверяет создание приложения, валидацию версии и имени
- **User** - Проверяет создание пользователей, валидацию email, уникальность, CRUD операции
- **Currency** - Проверяет создание валют, валидацию данных, методы поиска
- **UserCurrency** - Проверяет подписки пользователей на валюты, историю изменений

### 2. `test_utils.py` - Тесты утилит

Тесты для вспомогательных функций:

- **get_all_currencies_data** - Проверяет получение данных о всех валютах
- **update_all_currencies** - Проверяет обновление курсов валют
- **UserCurrencyExtended** - Дополнительные тесты для истории подписок

### 3. `test_author.py` - Расширенные тесты моделей

Расширенные тесты для классов Author и App:

- Проверка всех сценариев валидации
- Граничные условия
- Обработка ошибок

### 4. `test_http_handler.py` - Тесты HTTP-обработчика

Тесты для класса `SimpleHTTPRequestHandler`:

- Обработка различных GET-запросов
- Проверка маршрутов ('/', '/author', '/currencies', '/users', '/user?id=X')
- Обработка неизвестных маршрутов
- Проверка корректности передачи данных в шаблоны

### 5. `test_get_currency.py` - Тесты API валют

Тесты для функций получения данных о валютах:

- Проверка получения конкретных валют
- Обработка ошибок соединения
- Обработка некорректных ответов API
- Валидация формата данных

### 6. `test_control_main.py` - Интеграционные тесты

Тесты для проверки работы всего приложения:

- Запуск HTTP-сервера
- Интеграционное тестирование всех маршрутов
- Проверка отображения данных на страницах

## Покрытие тестами

Тесты обеспечивают полное покрытие следующих аспектов:

- **Модели данных**: Все классы и их методы протестированы
- **Валидация**: Все проверки данных протестированы
- **CRUD операции**: Создание, чтение, обновление, удаление данных
- **HTTP маршруты**: Все маршруты приложения протестированы
- **Обработка ошибок**: Все возможные ошибки протестированы
- **Граничные условия**: Все краевые случаи протестированы

## Запуск тестов

Для запуска всех тестов:

```bash
python -m pytest tests/ -v
```

Для запуска с помощью unittest:

```bash
python -m unittest discover tests/ -v
```

## Особенности реализации

1. **Изоляция тестов**: Каждый тест очищает состояние хранилища перед выполнением
2. **Mock-объекты**: Используются для изоляции компонентов
3. **Проверка исключений**: Все ожидаемые исключения протестированы
4. **Проверка вызовов**: Используется mock для проверки вызовов методов
5. **Проверка данных**: Все возвращаемые данные проверяются на корректность

## Требования к тестам

- Все тесты проходят без ошибок
- Каждый тест тестирует одну конкретную функциональность
- Тесты независимы друг от друга
- Используется понятная номенклатура имен тестов
- Тесты покрывают как положительные, так и отрицательные сценарии
